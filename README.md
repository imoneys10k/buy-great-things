# buy-great-things

一个独立商品档案网站。记录具体商品的制造地、材质、工艺、资料来源和证据缺口。

## 项目定位

- 不销售，不做导购推荐，不提供购买链接、购买渠道或外部跳转。
- 优先非中国制造，不能用品牌国籍替代制造地。
- 中国制造仅在同类品质冠绝且证据充分时允许例外。
- 初版是前端与资料建档展示；首批商品未完成独立品质审定。

## 开发

无框架、无构建依赖。运行 `python3 -m http.server 4173 --directory dist`，打开 `http://localhost:4173`。

运行 `node scripts/check.mjs` 验证数据、资源和页面规则。修改 `dist/products.js` 更新档案；原始资料与图片出处见 `SOURCES.md`。收藏只保存在访问者浏览器，不会上传。

## 发布

GitHub Actions 将 `dist/` 部署到 GitHub Pages，推送 `main` 后自动更新。网站使用相对资源路径，兼容仓库子目录。

## 速度与流畅度

前端使用原生 HTML/CSS/JavaScript，无框架运行时、第三方脚本、在线字体或商品接口。图片以 WebP 本地托管，首屏图片优先加载，其余图片懒加载；筛选与收藏直接在本地完成，不等待网络。无持续动画、滚动监听或后台轮询。CI 验证页面代码不超过 50 KB、单张图片不超过 100 KB。实际访问时间受 GitHub Pages 与用户网络影响。

## 内容维护

保留具体型号、制造说明范围、资料查阅日期、未解决问题和资料状态。品牌陈述不作为独立测试结果。未经证据审核，不得将“资料建档”改成“品质审定”，不得编造评分、实测、正品认证或品质冠军结论。

品牌图片用于识别和前端展示，权利归原品牌；不代表品牌合作或授权。正式运营前需确认图片使用权限，或替换成自有摄影。
